# CÓMO DICTAN LOS MÉDICOS (convenciones de ejemplo)
- Al principio pueden decir el nombre del paciente: NO va en el informe.
- "protocolo normal" = usar el PROTOCOLO NORMAL de la plantilla del estudio.
- "protocolo normal pero adicionamos X" = protocolo normal + X como última viñeta.
- "punto y aparte" = nueva viñeta. "punto seguido" = misma viñeta, nueva oración.
- "barra" = "/". "dos puntos" = ":". "fin" / "punto final" = terminó el dictado.
- "hora 11" (mama) = H11. "L5, S1" = L5-S1.
- Medidas: "23 por 24" = "23 x 24mm".
- Correcciones ("perdón", "mejor dicho"): usar lo último que se dijo.
- Si un dato no se entiende, escribir [[COMPLETAR: dato]]. Nunca suponerlo.
